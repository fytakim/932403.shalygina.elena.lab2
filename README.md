**Вариант:** 11 (Тема «Фотограф и визуальный сторителлер»)

## Описание работы

В проекте реализованы следующие элементы согласно техническому заданию:
* Страница из лабораторной №1 оформлена во внешнем файле `style.css`.
* Использованы три способа задания стилей: внешний файл, одно правило для ссылок в `aside` во внутреннем блоке `<style>` и inline-свойство `z-index: 10` у подписи фотографии.
* В `:root` заданы переменные основного серого цвета, синего акцента, цвета текста и шрифта.
* Показаны `position: static` у заголовков `h2`, `relative` у контейнера фотографии и `absolute` у подписи поверх фотографии.
* При наведении изображение в `header` увеличивается внутри контейнера с `overflow: hidden`, при нажатии становится чёрно-белым.
* Реализованы состояния `:hover`, `:active`, `:focus` и `:visited`.
* Использованы контрастные цвета текста и фона.

Код веб-страницы валиден и успешно проходит проверку через W3C Validator.
